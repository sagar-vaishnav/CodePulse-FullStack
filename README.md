CodePulse-FullStack

CodePulse-FullStack is a modern full-stack blogging and content management platform built using Angular and ASP.NET Core Web API. The project demonstrates real-world enterprise-level development practices including authentication, role-based authorization, clean architecture, RESTful APIs, state management, and responsive UI design.

This project was created as a portfolio-ready showcase application to demonstrate end-to-end full-stack development skills using modern Microsoft and Angular technologies.
