# 🚀 CodePulse-FullStack

A modern **Full Stack Blogging Platform** built using **Angular** and **ASP.NET Core Web API**.  
This project demonstrates enterprise-level application development practices including authentication, authorization, RESTful APIs, clean architecture, reusable UI components, and scalable backend development.

---

# 📌 Project Overview

**CodePulse-FullStack** is a portfolio-ready full-stack application designed to showcase real-world development skills using modern Microsoft and Angular technologies.

The application allows users to:
- Register & authenticate securely
- Create and manage blog posts
- Organize content with categories
- Perform CRUD operations
- Access protected APIs using JWT authentication
- Experience responsive and user-friendly UI

🚀 Getting Started
Prerequisites
Make sure you have installed:

Node.js

Angular CLI

.NET SDK

SQL Server

Visual Studio / VS Code

⚡ Frontend Setup
cd frontend
npm install
ng serve
Frontend runs on:

http://localhost:4200
⚡ Backend Setup
cd backend
dotnet restore
dotnet run
Backend API runs on:

https://localhost:xxxx
🗄️ Database Migration
Run Entity Framework migrations:

dotnet ef database update
